# Adversarial Patch Game

An interactive web-based game for exploring adversarial patches and image classification.

This project was developed as part of an MSc project and allows users to interact with adversarial image patches, place them on images, and observe how the model's prediction changes.

## Features

- Interactive adversarial patch placement
- Image classification using a pretrained model
- Multiple patch sizes
- Multiple target classes
- Web-based user interface
- Real-time model prediction
- Submission and scoring mechanism

## Requirements

Install the required Python packages:

pip install -r requirements.txt
Running the Application

Run:

python app.py

Then open the local address shown in the terminal, for example:

http://127.0.0.1:5000
## Model and Dataset

The application uses pretrained model files and image data.

The following directories are not included in the GitHub repository by default:

data/
saved_models/

These files need to be prepared separately before running the full application.


## Purpose

The project investigates how adversarial patches affect image classification models and explores how adversarial machine learning concepts can be communicated through an interactive game interface.
